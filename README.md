# India Notice Nest

I want to build a website for legalnoticeboard.com.

1. At the root (/), build a simple, dignified, and professional coming soon page for Legal Notice Board in India. It should highlight transitioning legal public notices from scattered print newspapers to a centralized, permanent, searchable online platform for everyday businesses and individuals. Do not include a waitlist. Include notice category tags, core benefits (permanent record, nationwide search, verification), and contact info.
2. At /home, build the real platform preview ("the real deal" for after testing): a fully featured public notice portal where users can search, filter, and view published legal notices (such as Property Title Investigation, Lost Documents, Court & Dispute Notices, Corporate Filings), and access a "Post a Notice" submission flow.
